# Project ZENTRIX — Web 端 UI 设计清单

**文档目的**：将 `proposal.md`、`responsibility.md`、`technicals.md`、`database.md` 中定义的 Web 职责，拆解为可实现的页面与 UI 模块，作为 Web 端信息架构与界面设计的基础。

---

## 1. Web 端定位

Web 端是 ZENTRIX 的账户与商业化门户，主要承担以下职责：

- 账户注册、登录、找回密码与基础资料管理
- Desktop 端授权与设备管理
- 课包浏览、购买、已购资产管理
- 会员购买、订阅状态管理与订单管理
- 成就、等级、勋章与学习进度总览展示
- 个人中心与基础设置

Web 端不承担具体课包内的编码、运行、提交与进度推进，因此 UI 设计应偏向“管理、查看、购买、确认”而不是“学习编辑”。

---

## 2. 信息架构

建议 Web 端采用以下一级导航：

- 首页 / 控制台
- 课包市场
- 我的课包
- 会员中心
- 订单中心
- 成就与进度
- 设备与授权
- 个人设置

如果后续首页承担营销展示功能，可额外增加公开区：

- 产品介绍
- 价格方案
- 常见问题
- 登录 / 注册入口

---

## 3. 公共 UI 组件

以下组件会在多个页面复用，应优先统一设计：

- 顶部导航栏：Logo、主导航、搜索、登录态入口、通知入口
- 用户菜单：头像、昵称、账户信息、退出登录
- 状态标签：已购买、未购买、订阅中、已过期、待支付、已授权、未授权
- 统计卡片：已购课包数、有效会员、累计学习进度、获得成就数
- 列表空状态：无订单、无课包、无设备、无成就时的提示与引导按钮
- 侧边栏 / 二级导航：用于个人中心、订单中心、授权管理等管理页
- 表格与筛选条：订单、设备、授权记录等列表场景
- 弹窗 / 抽屉：确认购买、解绑设备、申请找回密码、查看订单详情
- 表单组件：登录、注册、找回密码、资料编辑、授权绑定

---

## 4. 页面级 UI

### 4.1 公开首页 / 营销页

用于未登录用户了解产品，也可作为登录后的默认落点。

需要的 UI：

- 首屏产品介绍区：产品名称、核心卖点、主行动按钮
- 功能概览区：学习执行端在 Desktop，Web 负责账户与商业化的说明
- 课包推荐区：精选课包、热门课包、新上架内容
- 会员方案区：会员权益、适用场景、购买入口
- 用户评价 / 成果展示区：学习成果、成就展示、真实案例
- FAQ 区：支付、授权、设备、学习方式等常见问题
- 页脚区：帮助中心、协议、隐私、联系入口

### 4.2 登录 / 注册 / 找回密码

用于账户体系入口，和项目自实现认证流程对应。

需要的 UI：

- 登录表单：邮箱 / 用户名、密码、登录按钮
- 注册表单：昵称、邮箱、密码、确认密码、协议勾选
- 找回密码表单：邮箱验证、重置密码链接、重置密码输入
- 第三方登录入口：若后续接入第三方账号绑定，可预留按钮区域
- 校验提示：字段错误、验证码失效、密码强度、重复注册
- 安全提示：异常登录提醒、会话过期提示

### 4.3 首页控制台

登录后的默认首页，集中展示用户状态与关键入口。

需要的 UI：

- 概览统计：已购课包、有效会员、未完成订单、设备授权数
- 最近访问：最近打开的课包、最近查看的订单、最近授权设备
- 学习进度总览：只读进度条、阶段状态、最近同步时间
- 成就摘要：最新获得的成就、等级、勋章预览
- 续费 / 购买提示：会员即将到期、课包未购买、授权不足等提醒
- 快捷入口：去课包市场、查看我的课包、管理设备、查看订单

### 4.4 课包市场

用于浏览、筛选与购买课包。

需要的 UI：

- 课包卡片：封面、标题、简介、难度、标签、价格、购买状态
- 筛选栏：分类、难度、价格区间、语言、上新时间、是否已购
- 搜索框：按课包名称、关键词、标签检索
- 排序控件：推荐、最新、价格、热度
- 详情入口：查看课包介绍、目录、适合人群、权益说明
- 购买按钮：立即购买、加入购物车或直接订阅（若后续支持）

### 4.5 课包详情页

用于承接购买决策。

需要的 UI：

- 课包封面与标题区
- 核心信息区：价格、更新状态、语言、难度、时长、适合人群
- 目录预览区：章节树、课程范围、可解锁内容
- 权益说明区：购买后可用范围、授权条件、是否包含会员权益
- 讲师 / 团队信息区：若后续有内容作者展示需求
- 用户评价 / 购买人数区：若后续开放评价体系，可预留位置
- 购买确认模块：优惠信息、支付按钮、订单说明

### 4.6 我的课包

用于展示已购买或已获得学习资格的内容资产。

需要的 UI：

- 已购课包列表：状态、有效期、更新时间、入口按钮
- 资产状态标签：可学习、待激活、已过期、已下架
- 快捷操作：查看详情、查看权益、前往 Desktop 打开
- 权益说明面板：当前拥有的授权范围、到期时间、剩余额度
- 空状态引导：尚未购买课包时跳转市场页

### 4.7 会员中心

用于展示和管理会员权益。

需要的 UI：

- 当前会员状态卡：是否有效、到期时间、自动续费状态
- 权益列表：可访问内容、折扣、专属权益、优先支持等
- 套餐对比表：不同会员档位的功能差异
- 开通 / 续费按钮：进入支付流程
- 历史订阅记录：订阅变更、续费、过期、退款状态

### 4.8 订单中心

用于查询课包、会员、支付相关订单。

需要的 UI：

- 订单列表：订单号、类型、金额、状态、创建时间、操作
- 筛选条件：订单类型、状态、时间范围、支付渠道
- 订单详情页：商品明细、优惠信息、支付信息、状态流转
- 支付引导区：待支付订单的继续支付、取消订单入口
- 退款信息区：若后续支持退款，可显示申请状态与结果

### 4.9 成就与进度

用于展示非学习执行类的可视化结果。

需要的 UI：

- 成就墙：图标、名称、说明、达成时间、稀有度
- 等级展示：当前等级、经验进度、下一等级目标
- 勋章展示：已获得勋章、未解锁勋章
- 学习进度总览：按课程 / 章节 / 课时聚合的只读进度条
- 进度明细：最近完成项、最近同步时间、关联课包

### 4.10 设备与授权

用于管理 Desktop 端授权与设备绑定。

需要的 UI：

- 授权状态卡：当前授权是否有效、授权范围、失效时间
- 设备列表：设备名称、系统、绑定时间、最后活跃时间、状态
- 绑定流程：绑定码输入、确认绑定、绑定结果
- 解绑操作：确认弹窗、风险提示、解绑成功反馈
- 授权记录：激活、续期、撤销、过期等历史日志
- 安全提醒：设备超限、授权异常、异地登录提示

### 4.11 个人设置

用于账户资料与基础偏好配置。

需要的 UI：

- 基础资料编辑：头像、昵称、简介、邮箱展示
- 安全设置：修改密码、登录保护、会话管理
- 通知设置：邮件通知、购买通知、授权提醒、进度提醒
- 账号绑定：第三方账号绑定与解绑
- 数据与隐私：导出、注销、协议查看入口

## 5. 核心交互流

Web 端需要重点覆盖以下交互路径：

- 注册 / 登录 / 找回密码
- 浏览课包 → 查看详情 → 下单支付
- 登录后查看已购课包与会员状态
- 绑定 Desktop 授权设备
- 查看订单与支付结果
- 查看成就、等级和进度总览
- 修改个人资料与安全设置

其中“购买成功后前往 Desktop 继续学习”应作为关键引导，明确把 Web 与 Desktop 的职责分开。

---

## 6. 状态设计

建议统一设计以下状态：

- 未登录
- 已登录
- 登录失效
- 未购买
- 已购买
- 订阅中
- 已过期
- 待支付
- 支付中
- 支付失败
- 已授权
- 未授权
- 设备超限
- 数据同步中
- 数据同步失败

这些状态应在按钮、标签、卡片和空状态中保持一致，避免同一概念在不同页面出现不同文案。

---

## 7. UI 设计原则

- 优先清晰和高密度信息展示，少做装饰性堆叠
- 购买、授权、订单等管理页面以表格、卡片、列表为主
- 学习执行相关能力只做跳转和结果展示，不在 Web 端伪装成编辑器
- 所有“下一步动作”都要明确，例如购买、续费、绑定、查看详情
- 进度、成就、授权状态都应可被快速扫描
- 公开营销区和登录后控制台要明确区分

## 8. 建议落地优先级

### MVP 优先实现

- 登录 / 注册 / 找回密码
- 首页控制台
- 课包市场与课包详情
- 我的课包
- 会员中心
- 订单中心
- 设备与授权
- 个人设置

### 后续增强

- 成就墙与勋章体系
- 学习进度更细粒度的可视化
- FAQ、公告、消息通知中心
- 评价、推荐、内容作者展示
- 退款、发票、更多商业化能力

---

## 9. 结论

如果只看 Web 端，ZENTRIX 的 UI 本质上是一个“账户 + 资产 + 商业化 + 结果展示”的管理门户。页面重点不在学习过程本身，而在于把学习资格、购买关系、设备授权、进度结果与账号状态展示清楚，并把用户稳定地引导到 Desktop 端继续学习。
