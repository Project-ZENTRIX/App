# Stage 6 UI 任务拆解

下面把 `zentrix-web` 的 UI 变动拆成可执行任务，按优先级和交付顺序排列。建议先做全站统一壳和权限侧栏，再推进各类页面模板。

## P0. 统一外壳与权限侧栏

- [ ] 抽出并统一左侧栏、顶部栏、主内容区壳层。
- [ ] 让共享壳只保留一套导航结构，不再让各页面维护自己的壳布局。
- [ ] 保持移动端抽屉式侧栏，确保主内容区在窄屏下可用。
- [ ] 把当前用户角色写回侧栏底部，不再固定显示为管理员。
- [ ] 为侧栏加入权限控制逻辑。
- [ ] 管理分组按权限显示或隐藏，至少覆盖 `管理员`、`内容包` 这类特权入口。
- [ ] 对不可见但保留的入口定义统一状态：隐藏、禁用、锁定说明三选一，不要混用。
- [ ] 基础分组 `仪表盘 / 学习 / 账户 / 设置` 保持可见，但子项要能按身份裁剪。

## P1. 页面模板统一

### 仪表盘

- [ ] 统一三类首页的页面头部样式：标题、副标题、动作按钮。
- [ ] 将首页内容组织成指标卡、最近状态、快捷入口三种区块。
- [ ] 分别整理学生、教师、管理员首页的主动作，避免所有身份看到同一组按钮。

### 列表页

- [ ] 为课程、内容包、设备、订单、资料库统一列表布局。
- [ ] 列表页补齐搜索、筛选、状态标签和行内操作。
- [ ] 表格区域支持横向滚动，避免窄屏列内容被压缩。
- [ ] 列表页按钮和状态样式统一到共享组件。

### 详情页

- [ ] 为课程、内容包、设备、订单统一详情页结构。
- [ ] 详情页拆成概览区、明细区、操作区三层。
- [ ] 强化版本、授权、支付、更新时间等高频信息的展示权重。
- [ ] 保留返回列表、版本管理、撤回、解绑、审核等关键动作。

### 设置页

- [ ] 将个人资料、通知、安全、会话统一成设置子导航 tabs。
- [ ] 统一设置页的表单、开关、危险操作和提示样式。
- [ ] 会话页保留当前会话状态、设备列表、单条撤销和全部退出。

### 管理页

- [ ] 管理员工作区改为控制台布局，而不是普通信息页。
- [ ] 用户管理、内容包审核、系统状态、许可证概览都以卡片化指标呈现。
- [ ] 把特权入口放到页面主操作区，避免埋在次级导航里。

## P2. 身份变体页

- [ ] 学生侧页面聚焦进度、课程、设备、订单、会员。
- [ ] 教师侧页面聚焦内容包编写、发布、审核流转。
- [ ] 三类身份页复用同一套组件风格，但调整信息密度和动作优先级。
- [ ] 确认学生/教师/管理员之间的导航和按钮文案一致且可区分。

## P3. 视觉与一致性收口

- [ ] 统一卡片、徽章、按钮、表格、标签页组件样式。
- [ ] 统一页面标题区排版，固定为标题 + 副标题 + 动作按钮。
- [ ] 明确状态标签体系，避免只靠颜色表达状态。
- [ ] 让整体气质保持产品后台风格，减少装饰性内容。

## 验收标准

- [ ] 不同身份进入时，侧栏菜单会按权限变化。
- [ ] 管理入口不会在无权限用户侧栏中误导显示。
- [ ] 列表、详情、设置、管理四类页面都能落到统一模板上。
- [ ] 移动端侧栏和主内容区在窄屏下仍能正常工作。
- [ ] 全站导航、标题层级、操作区和状态展示保持一致。
