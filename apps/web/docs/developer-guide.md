## 读法

- 想看项目整体怎么启动，先看“总体说明”。
- 想看某个页面为什么放在某个布局里，先看“布局层”和“应用壳与导航”。
- 想新增页面，先看“页面原语”和“业务路由模块”。
- 想改视觉、主题或文案组织方式，先看“国际化、主题与样式”。
